# E-Commerce API Testing

## Project Overview
This project focuses on manual API testing of E-Commerce APIs using Postman.

## Tools Used
- Postman
- REST API
- JSON
- HTTP Methods

## APIs Tested
- Products API
- Product Creation API
- Product Update API
- Product Deletion API
- Product Search API

## HTTP Methods Used
- GET
- POST
- PUT
- PATCH
- DELETE

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- Boundary Testing
- Response Validation
- Status Code Validation
- API Chaining

## Status Codes Tested
- 200 OK
- 201 Created
- 400 Bad Request
- 401 Unauthorized
- 403 Forbidden
- 404 Not Found

## Project Structure
Postman/
- E-Commerce_API_Testing.postman_collection.json

## How to Run
1. Import the Postman collection.
2. Set the required environment variables.
3. Run the API requests.
4. Validate status codes and responses.
5. Execute positive and negative test cases.

## Key Scenarios
- Retrieve products
- Create a product
- Update product details
- Delete a product
- Validate invalid requests
- Validate API responses
